# Riah Studio

Small local tools and free browser games.

- **[Riah Usage](https://github.com/RiahStudio/riah-usage)** — local AI subscription usage dashboard (Claude, Cursor, Codex, and more)
- **[Riah To-Do](https://github.com/RiahStudio/riah-todo)** — Windows tray to-do by the clock
- **[Riah Extensions](https://github.com/RiahStudio/riah-extensions)** — small readable browser extensions; minimal permissions, no telemetry
- **[Riah Swipe](https://riahstudio.com/riahswipe/)** — Tinder-style review for AI image batches
- **[Basketballatro](https://riahstudio.com/basketballatro)** — free browser NBA roguelike deckbuilder
- **[Meme Academy](https://memelord.riahstudio.com/mwa/)** — no-install multiplayer meme party game

Honest limits on every product page. Site: https://riahstudio.com
