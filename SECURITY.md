# Security

This policy covers every public RiahStudio repository that doesn't have its own
SECURITY.md.

## Reporting a vulnerability

Please report it privately: open the repository's **Security** tab and choose
**Report a vulnerability**. If that isn't available, use the contact path at
<https://riahstudio.com/>.

Please don't open a public issue for an active vulnerability until there has been
time to look into it and ship a fix.

## What we do on our side

- Secret scanning and push protection are on for public repos.
- Dependabot alerts and security updates are on.
- Public releases are cut from a clean, reviewed copy, never by flipping a private
  repo public.
